# whataifound.org

The record of what AI has actually discovered.

A curated registry of scientific and mathematical results produced by or with AI systems, graded
on how they were verified and how much the AI actually did. Results that turned out to already
exist in the literature stay on the record. That's the point.

## Run it

The site files live in `app/`, but `assets/` and `data/` sit at the repo root and are shared by
`vercel.json` rewrites, so `app/` must be served **as the site root**, the same way it deploys.
`serve.py` reads `vercel.json` and reproduces those rewrites locally, with no symlinks and no build:

```bash
python3 serve.py          # http://localhost:8000
python3 serve.py --lan    # bind all interfaces for phone testing on the same Wi-Fi
```

Or, if you have the Vercel CLI, `vercel dev` runs the real platform locally at `http://localhost:3000`.

The `fetch()` for `data/entries.json` needs a server; opening `index.html` directly via `file://`
will show a fallback message. Opening `/app/index.html` from a plain server rooted at the repo will
404 on the logos and the registry data; `app/` has to be the root, which is what `serve.py` (and
`vercel.json` in production) handle.

Still no build step and no external requests: `index.html` links `styles.css` and `app.js` as
plain static files. The only inline script is a two-line theme initialiser in the `<head>` that
runs before first paint to avoid a flash. **Theme defaults to dark** for a first-time visitor
(no stored choice); the toggle offers Light / System / Dark and persists the pick in `localStorage`,
where "System" follows `prefers-color-scheme` and the other two override it.

Type is one family, Newsreader: a classic news serif in the AP/NYT/WSJ vein, deliberately too
old-school to read as tech. It sets everything, headlines to the smallest metadata labels. Reading
text uses old-style figures; numeric chrome (stats, dates, chart values) switches to lining tabular
figures, and labels lean on uppercase with letter-spacing for a newspaper small-caps feel. Four
weights (400, 400 italic, 500, 600) are served from `assets/fonts/` rather than a CDN, so the page
has no external dependencies and renders identically offline. The font licence (SIL OFL 1.1) travels
with the files in `assets/fonts/OFL.txt`.

The registry (search bar and list) is the default view, so the most recent finding peeks into view
on load. A **Visuals** button in the header actions is a disclosure toggle that reveals `#panel-visuals`
in place below the list. It holds four small bar charts (`#charts`, built by `renderCharts()`) computed live from the entries:
findings per year, by verification grade, by lab, by topic area. They are plain HTML/CSS/SVG, no
chart library, and always reflect the whole registry rather than the active filter. Magnitude uses a single
accent hue (categories are named by text labels, not distinguished by color); the grade chart adds
the semantic pill colors as decorative swatches only. The palette was checked with the dataviz
validator, which flagged that the eight verification colors fail as a *categorical* set (author vs
disputed are too close), which is why bars are single-hue and identity rides on the labels.

A `.labs-hub` section links straight to each lab's own discovery hub (`anthropic.com/science`,
`openai.com/research`, `deepmind.google/science`) using the logos in `assets/external-logos/`. The
OpenAI mark is the dedicated symbol file from Commons, not a crop of the wordmark.

## Responsive

One fluid layout from 320px phones through iPad to desktop, verified by rendering at each width.
Breakpoints at 720px (entry rail moves above the body) and 560px (compact, non-sticky filter bar;
buttons and stats reflow). A `pointer: coarse` block enlarges tap targets and forces 16px inputs so
iOS and iPadOS do not zoom on focus. Safe-area insets (`env(safe-area-inset-*)` with `viewport-fit=
cover`) keep content clear of notches, the sticky bar carries the `-webkit-backdrop-filter` prefix
for Safari, and long strings (formulas, model names) wrap rather than overflow.

## Accessibility

Built to WCAG 2.1 AA. A skip link, `role="search"` on the filter bar, and a polite live region
(`#count`) that announces the result count as you filter. Heading structure runs h1 (page) to
section h2/h3 to entry h2; every chart carries a `role="img"` label summarising its data for screen
readers. Visible `:focus-visible` rings on all interactive elements; `prefers-contrast: more` and
`prefers-reduced-motion` are both honoured. All text and pill colours were checked against the AA
contrast threshold (muted text 5.4:1, white-on-pill 4.9:1 or better).

A **theme switch** (sun / monitor / moon, top right) chooses light, system, or dark, persisted in
`localStorage` and applied by a tiny inline `<head>` script so there is no flash on load. A manual
choice beats the OS setting via a `:root[data-theme="..."]` override; "system" removes the
attribute and defers to `prefers-color-scheme`. Switching radiates the new theme out from the
click using the View Transitions API (a circular `clip-path` reveal), and falls back to an instant
swap where that API is absent or `prefers-reduced-motion` is set.

The **Methodology** button opens `methodology.html`, a styled page that presents the verification
and autonomy grades (with the same coloured pills) and the editorial rules, rather than surfacing
`SCHEMA.md` as raw markdown. `SCHEMA.md` remains the canonical field reference for editors.

## Deployment (Vercel)

Static deploy, no build command. `vercel.json` does the routing: `app/index.html` is served at `/`,
`app/methodology.html` at `/methodology` (`cleanUrls` on), and `/assets/*` and `/data/*` resolve to
the root-level folders so the shared data and images live in one place. Fonts get a one-year
immutable cache header; `data/entries.json` is set `must-revalidate` so registry edits go live
immediately; the feeds are cached 30 min. Every route was smoke-tested locally against the rewrites
and returns 200.

**Security headers** are applied to every response via a `/(.*)` block: `Content-Security-Policy`
(scoped to what the site actually loads: self + inline scripts/styles, `youtube-nocookie` frames,
Vercel insights), plus `X-Content-Type-Options`, `X-Frame-Options`, `Referrer-Policy`,
`Strict-Transport-Security`, and `Permissions-Policy`. The CSP was verified against a locally served
copy with the real headers: every entry, chart, logo, font, and the click-to-load YouTube embed pass
with no violations. If you add a new external resource, widen the matching CSP directive or it will
be blocked.

**404 page.** `app/404.html` is a self-contained, theme-aware not-found page (inline CSS, absolute
asset paths so it renders at any URL depth), wired via a `/404.html` rewrite.

Two dashboard toggles are needed after the first deploy: enable **Web Analytics** and **Speed
Insights** on the project. The loader snippets are already in both pages (`/_vercel/insights/*` and
`/_vercel/speed-insights/*`); they are cookieless, privacy-friendly, and no-op until enabled.

## Discovery / SEO

Built to be found and cited by both classic search and AI answer engines (ChatGPT, Perplexity,
Google AI Overviews, Claude):

- **Canonical URLs** on both pages, pointing at the clean-URL form, so ranking never splits across
  `/methodology` vs `/methodology.html`.
- **Encompassing titles and descriptions** that name the disciplines (math, physics, biology, CS),
  the models (Claude, GPT, Gemini/DeepMind), and both grading axes, phrased around what people
  actually search ("what has AI actually discovered", "verified AI proofs").
- **Structured data (JSON-LD):** `WebSite` + `SearchAction`, a `Dataset` node pointing at
  `data/entries.json`, and an `FAQPage` answering the core questions on the home page; a
  `TechArticle` on the methodology page. This is the main lever for accurate AI-engine citation.
- **Open Graph + Twitter cards** with a 1200×630 **`assets/brand/og.png`**, so links shared into
  WhatsApp, iMessage, Facebook, LinkedIn and X unfurl with a rich preview. It must be PNG, not SVG;
  those platforms silently drop SVG `og:image`. `assets/brand/og.svg` is the editable source;
  regenerate the PNG after editing it with:

  ```bash
  npm i @resvg/resvg-js
  node -e "const{Resvg}=require('@resvg/resvg-js');const fs=require('fs');\
  const r=new Resvg(fs.readFileSync('assets/brand/og.svg','utf8'),{fitTo:{mode:'width',value:1200},\
  font:{fontFiles:['assets/fonts/news-600.woff2','assets/fonts/news-400.woff2'],loadSystemFonts:true,\
  defaultFontFamily:'Newsreader'}});fs.writeFileSync('assets/brand/og.png',r.render().asPng())"
  ```
- **`robots.txt`** explicitly welcomes AI crawlers (GPTBot, OAI-SearchBot, ClaudeBot, PerplexityBot,
  Google-Extended, Applebot-Extended, CCBot) and points to **`sitemap.xml`**.
- **SVG favicon + mask-icon** from the brand mark.

**Canonical domain:** `https://whataifound.org`. It appears in `app/index.html`,
`app/methodology.html`, `robots.txt`, `sitemap.xml`, and `build-feed.py` (its `SITE` constant) — if it
ever changes, update all five and re-run `python3 build-feed.py` to regenerate `feed.xml` and
`feed.json`. At launch, submit `sitemap.xml` in Google Search Console.

## Permalinks, feeds, and data reuse

- **Per-entry permalinks.** Every entry renders with a stable `id="e-<entry-id>"` and a `#` copy-link
  affordance beside its title (visible on hover, always visible on touch). Clicking it copies the
  full deep link and updates the URL. Opening a `#e-…` link (fresh load or in-page) scrolls to that
  entry, opens its details disclosure, and briefly highlights it. The list is rendered client-side,
  so this is handled in `app.js` (`revealFromHash`, on load and on `hashchange`) rather than by the
  browser's native anchor jump, which fires before the entries exist.
- **Feeds.** `feed.xml` (RSS 2.0) and `feed.json` (JSON Feed 1.1) are generated from
  `data/entries.json` by `build-feed.py`, sorted newest-*added* first, and advertised via
  `<link rel="alternate">` in both pages plus footer links. Regenerate after editing the registry:

  ```bash
  python3 build-feed.py     # rewrites feed.xml + feed.json
  ```

  The feeds are committed (there is no build step on Vercel), so remember to re-run and commit them
  whenever `data/entries.json` changes. Cached 30 min at the edge (`s-maxage=3600`).
- **License and citation.** `LICENSE` dual-licenses the project: registry data and editorial content
  under **CC BY 4.0**, site code under **MIT**. The footer carries a "Use the data" block (JSON
  download + feed links + license) and a "How to cite" block whose retrieval date is filled at
  runtime. The `Dataset` JSON-LD already points at `data/entries.json` as a `DataDownload`.

## Current state

21 backfilled entries spanning July 2021 (AlphaFold2) to July 2026 (Jacobian conjecture
counterexample). Entries are graded conservatively. Four are deliberately negative results: two
graded `known` (the GPT-5 convex-optimization claim and the GPT-5 "10 Erdős problems" episode) and
two `disputed` (the GNoME materials predictions and the A-Lab autonomous-synthesis claims). Showing
the failure modes is what makes the rest credible.

The eleven real, pre-2026 findings also carry a `discussion` field linking to the Hacker News and
press threads where each result was argued over. The future-dated entries (the 2026 Jacobian,
unit-distance, and Erdős results) deliberately have none: no verifiable thread exists to point at
yet, and inventing one would defeat the purpose of the registry.

Three entries carry `videos`: click-to-load YouTube explainers whose IDs and channels were
verified against YouTube's oEmbed endpoint before inclusion (Quanta Magazine and Yannic Kilcher
for AlphaTensor, the AI for Good summit for AlphaDev, Elvis Saravia for the IMO result). Nothing
loads from YouTube until the visitor presses play, which keeps the page's no-external-requests
default intact. FunSearch and GNoME have no credible explainer videos; they get none.

The Jacobian entry was independently re-verified during construction: symbolic recomputation
confirmed det J = −2 identically and that all three listed points map to (−1/4, 0, 0).

## Next steps

Done so far: **per-entry permalinks** (hash anchors + copy-link, deep-link reveal), **RSS + JSON
feeds** (`build-feed.py`), a **CC BY 4.0 / MIT license** with on-site "how to cite" and data
download, a **styled 404**, and **security headers**.

Roughly in order of remaining value:

1. **Company pages.** `/lab/anthropic`, `/lab/openai`, `/lab/deepmind`: a neutral scoreboard of
   verified contributions rather than benchmark scores. This is the growth engine; nobody else
   publishes it and people will link to it.
2. **Move to a static site generator** (Astro or Eleventy) once entry count passes ~40. Keep JSON
   or move to per-entry markdown with frontmatter. Per-entry files make git history far more
   readable, which matters because the history is the credibility mechanism. This would also let the
   feeds regenerate on deploy instead of being committed by hand.
3. **Dedicated entry pages** with their own OG images, so sharing a specific finding unfurls with
   that finding's card rather than the site-wide one. (Hash permalinks already make entries linkable
   and citable; this is the richer-preview upgrade.)
4. **Submissions via GitHub PR.** Free moderation infrastructure and a public audit trail. Add an
   issue template mirroring the schema fields and a `CONTRIBUTING.md`.
5. **Challenge mechanism.** A structured way to contest an entry's novelty by citing prior work.
   This is where crowdsourcing genuinely works: refutation is objective and self-motivating,
   unlike voting on truth.
6. **Backfill deeper.** AlphaTensor (2022), AlphaDev (2023), the IMO 2024 AlphaProof/AlphaGeometry
   result, and the contested GNoME / A-Lab materials work are now in. Still to add: AlphaFold-adjacent
   results, the remaining ~10 verified Erdős contributions on Tao's wiki, and the First Proof
   challenge results (Feb 2026).

## Editorial rules that shouldn't drift

- Lab announcements enter at `claimed` no matter how confident the blog post is.
- Never delete an entry; downgrade `verification` and add to `caveats`. Quiet edits destroy trust.
- A novelty check gets written for every entry, including when it comes back clean.
- `autonomy` is graded on the strictest defensible reading of what the AI did.
- No hype verbs in titles.

See `SCHEMA.md` for full field definitions.

## Domain

The registry is **`whataifound.org`**, and the name of the project is the domain itself. A `.org`
reads as neutral infrastructure, which is what a registry should look like.

The domain string is not free-floating: it is the canonical URL in `app/index.html`,
`app/methodology.html`, `robots.txt`, `sitemap.xml`, and `build-feed.py`, and it is the wordmark in
`assets/brand/og.svg` and the header of both pages. Changing it means changing all of those and
re-rendering `og.png`.

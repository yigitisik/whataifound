Editorial policy

Announcements enter as claimed, however confident they sound. Nothing is ever deleted: entries are downgraded and annotated, and the history stays public. Every entry carries a novelty check, including when it comes back clean.

Use the data

The whole registry is one open file under CC BY 4.0 and can be reused anywhere with attribution. Take the file if you want everything; the API answers a narrower question, and promises a fixed set of fields the file does not.
